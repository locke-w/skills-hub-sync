## 3. 场景变奏规则（反同质化 · categoryId=279）

全库几十个人物如果都用同一句"空藤椅 + 午后金光 + 丁达尔尘埃"，平台会判定为模板化批量内容。规则：

1. **四层可变**：机位（15 种手法）· 实景（12 类空间）· 道具（人物 D4 信物 + 道具组）· 光影（10 种氛围）；
2. **每个槽位至少换两层**：与第 2 节"变奏方向"里最常见的默认组合相比，至少在两层上不同；
3. **道具必须来自人物**：每张场景图至少有 1 件该人物档案里的专属信物；
4. **同批次不撞组合**：同一批次内，同一槽位的"实景 + 光影"组合不重复；
5. **人设路由**：按 `github-diorama-staging-matrix.md` 的「人设身份与摆拍场景强制路由表」选实景；
6. **校验**：`validate_prompts.py --all` 会计算每个槽位跨人物的相似度，超过 `config/paths.yml` 中 `scene_similarity_threshold` 的会列出来，需改写至少两层后重出。

## 4. 封面候选（与 xiaohongshu 技能约定）

- 默认候选：**07 掌心温存**（尺度对比最强）、**10 时光重叠**（老照片 vs 立体手办的前后对比）；

- 画面里不写任何文字，封面大字由运营者后期叠加；
- 当某篇笔记的单一事件明显落在别的槽位（如母题 1 的工具特写），运营侧可选该槽位做封面，此时也应重出一张带留白的版本。

## 6. 出图验收清单（发布前逐张检查）

| 项目 | 通过标准 |
| :--- | :--- |
| 人物一致性 | 01 手办与 00 是同一个人：骨相、发型、专属信物一致；场景图里的手办与 01 一致 |
| 手部 | 五指、关节自然；07 掌心图无多指、断指、融合手指 |
| 尺度 | 6cm 胸像 / 12cm 全身像与手掌、杯子、钥匙等参照物比例合理 |
| 文字伪影 | 无英文字母、乱码、招牌字、水印、软件 logo |
| 材质 | 手办是哑光树脂质感：没有真人毛孔，也不是亮面塑料；底座为深色工艺品底座，不像石膏柱或墓碑 |
| 氛围 | 温暖、克制；无阴森暗角、惊悚光影、灵堂供桌意象 |
| 画幅 | 02–10 为 3:4；封面候选上 1/3 有干净留白 |
| 合规 | 无真实名人面孔，无网络真人照片垫图痕迹 |

任一项不过：改提示词对应层重出，不靠后期硬修。

## 7. 落盘与命名

- 提示词与档案（Obsidian）：`{material_base}/{char_dir}/character_profile.md`、`prompts.md`、`prompts.json`（可由 `validate_prompts.py --export-json` 从 `prompts.md` 生成）；
- 图片（3D 打印素材库）：`{asset_root}/{char_dir}/`，按第 1 节文件名保存，目录内只放图片；
