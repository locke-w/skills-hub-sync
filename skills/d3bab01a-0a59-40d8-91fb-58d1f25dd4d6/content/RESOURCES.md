# 全网最好用的智能体工具 资源

## 知识

- [LangChain 官方网站](https://www.langchain.com/)
  最全面的AI智能体开发框架，提供Python和JavaScript支持。用于：构建自定义智能体、集成各种LLM和工具。
- [AutoGPT GitHub 仓库](https://github.com/Significant-Gravitas/AutoGPT)
  自主智能体先驱项目，拥有17万+星标。用于：了解自主智能体模式、插件生态系统。
- [MetaGPT 论文与GitHub](https://github.com/geekan/MetaGPT)
  多智能体协作框架，模拟软件公司角色。用于：多智能体工作流、软件工程任务自动化。
- [CrewAI 文档](https://docs.crewai.com/)
  基于角色的多智能体团队编排框架。用于：快速搭建智能体团队、角色定义任务分解。
- [微软 Agent Framework 文档](https://learn.microsoft.com/en-us/agent-framework/)
  企业级AI智能体开发平台，支持.NET和Python。用于：企业自动化、多智能体工作流。
- [2026 AI Agent 框架对比指南](https://qubittool.com/zh/blog/ai-agent-framework-comparison-2026)
  详细对比LangGraph、OpenAI Agents SDK、Strands Agents、CrewAI等框架。用于：框架选型决策。
- [A Systematic Survey of LLM-Based Agentic AI Frameworks](https://pub.scientificirg.com/index.php/JSAA/article/view/534)
  学术论文，系统综述LLM智能体框架。用于：了解技术演进和理论基础。
- [Best AI Agent Frameworks 2026: LangChain, CrewAI, AutoGPT](https://www.remoteopenclaw.com/blog/ai-agent-frameworks-compared-2026)
  实时更新的框架对比文章，包含排名和优缺点分析。用于：快速了解市场格局。
- [GitHub AI Agent 排行榜](https://github.com/yuxiaopeng/Github-Ranking-AI/blob/main/Top100/AI%20Agents.md)
  基于星标的智能体项目排名。用于：发现热门项目和社区趋势。

  各框架的官方Issue跟踪和讨论区。用于：报告问题、参与开发和了解 roadmap。
