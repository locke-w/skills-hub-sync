# 6 大母题范例库（v5.0 · 真实视角版）

> 本文件给出 6 个母题的**可模仿范例**。每个范例都绑定素材库里的真实人物档案（信物、服饰、神态取自 `character_profile.md`），并使用合规视角：**A2 手艺人设计手记** 或 **B 第二人称代入**；母题 4 只给 **C 真实客户故事**的结构模板。
> 视角规则见 `copywriting-craft.md` 第 1 节；陈词滥调与禁写清单见同文件第 5 节。字数、字符数以 `scripts/validate_copy.py` 的计算为准。

## 🧩 人设特征 → 母题路由

```

```

## 母题 1：劳作者手记与手艺的温度 · A2 设计手记

- **人物**：char_52 摆修表摊修了一辈子钟表的老爷爷（胸像 6cm）
- **档案信物**：前额翻起的黄铜单目放大目镜、深灰竖条纹马甲口袋里的微型螺丝刀、装细螺丝的老锡盒；神态为微眯双眼、嘴唇微抿
- **单一事件**：设计时怎么处理额前那只目镜与眯着的眼

**正文**
> 设计这尊修表老爷爷，最费心思的是他额头上那只翻起的放大目镜。
>
> 目镜要翻在额前，黄铜镜筒压着几缕白发，低一分像戴着，高一分又像掉了。定稿时让他双眼微微眯着，嘴唇抿住——修表的人刚放下目镜，眼睛还收不回来。
>
> 马甲口袋里别着一支小螺丝刀，胸前那只老锡盒掀开一条缝，露出几颗细螺丝。
>
> 那双眯着的眼睛，是整尊手办最难做、也最像他的地方。
>
> 你家有没有这样一位老手艺人？更想留住他眯眼盯机芯的样子，还是抬头冲你笑的那一下？

**标题**
1. ⭐ `[手艺人手记型]` 修表老爷爷额前这只目镜，最费心思 (16字) 【提取自正文：最费心思的是他额头上那只翻起的放大目镜】
2. `[悬念留白型]` 这尊手办最难做的，是那双眯着的眼 (16字) 【提取自正文：那双眯着的眼睛，是整尊手办最难做……】
3. `[场景代入型]` 刚放下目镜的修表人，眼睛还收不回来 (17字) 【提取自正文：修表的人刚放下目镜，眼睛还收不回来】
4. `[反问共鸣型]` 你家也有一位这样的老手艺人吗 (14字) 【提取自正文：你家有没有这样一位老手艺人】
5. `[情绪反差型]` 那双眯着的眼，最难做也最像他 (14字) 【提取自正文：最难做、也最像他的地方】

**封面大字**：刚放下目镜的眼

## 母题 2：舌尖味蕾与柴米油盐 · B 第二人称

- **人物**：char_01 厨房忙碌慈祥外婆（胸像 6cm）
- **档案信物**：藏青盘扣斜襟衫、碎花围裙、银发髻、素银圈耳环、围裙口袋里的老花镜；神态为眯眼慈祥微笑
- **单一事件**：揭砂锅盖、尝第一口汤的那几秒

**正文**
> 你外婆家的灶台上，是不是也有一口用黑了的砂锅？
>
> 锅沿磕掉一小块，盖子上的气孔被蒸汽熏得发黄。她揭盖从不用抹布，两根手指捏着盖钮一提，白气扑了一脸也不躲，老花镜还插在围裙口袋里，眯着眼先尝一勺汤。
>
> 咸淡她只说两个字："正好。"
>
> 我们照着这样一位外婆，设计了一尊六厘米的小人：藏青盘扣衫，碎花围裙，银发挽成髻，耳垂上一对素银圈。
>
> 你记忆里那口锅，炖的是什么？更想留住她尝汤的样子，还是喊你吃饭的那一声？

**标题**
1. ⭐ `[场景代入型]` 你外婆家那口砂锅，是不是也用黑了 (16字) 【提取自正文：灶台上……一口用黑了的砂锅】
2. `[情绪反差型]` 咸淡她从不多说，只一句"正好" (15字) 【提取自正文：咸淡她只说两个字："正好。"】
3. `[反问共鸣型]` 你记忆里外婆那口锅，炖的是什么 (15字) 【提取自正文：你记忆里那口锅，炖的是什么】
4. `[数字锚点型]` 六厘米的外婆，耳垂上还有素银圈 (15字) 【提取自正文：六厘米的小人……耳垂上一对素银圈】
5. `[悬念留白型]` 白气扑了一脸也不躲，她先尝了一勺… (17字) 【提取自正文：白气扑了一脸也不躲……先尝一勺汤】

## 母题 3：嘴硬心软的倔老头 · B 第二人称

- **人物**：char_08 小区下棋倔老头爷爷（胸像 6cm）
- **档案信物**：橄榄绿灯芯绒翻领夹克、粗圆框老花镜、指尖的红木"帅"字棋子；神态为倔强专注里带一丝得意
- **单一事件**：一盘棋里，他嘴上不饶人、手上却让了一步

**正文**
> 你爷爷下棋，是不是也从来不让人？
>
> 楚河汉界一摆，他把老花镜往鼻梁上一推，指尖捏着那枚红木"帅"，半天不落。你走错一步，他啧一声，手却悄悄把你的"马"往回推了一格，嘴上还说："下不过就别下。"
>
> 输了他不认，赢了也不笑，只把棋子一颗颗码回木盒里。
>
> 我们按这样一位倔老头，设计了一尊六厘米的小人：橄榄绿灯芯绒夹克，粗框老花镜，眉头拧着，嘴角却绷不住。
>
> 你家也有这样的倔老头吗？更想留住他拧眉的样子，还是偷偷让棋的那只手？

**标题**
1. ⭐ `[情绪反差型]` 嘴上说下不过别下，手却偷偷让了棋 (16字) 【提取自正文：手却悄悄把你的"马"往回推……"下不过就别下"】
2. `[反问共鸣型]` 你爷爷下棋，是不是也从来不让人 (15字) 【提取自正文：首句】
3. `[场景代入型]` 捏着红木"帅"半天不落的倔老头 (15字) 【提取自正文：指尖捏着那枚红木"帅"，半天不落】
4. `[数字锚点型]` 六厘米的倔老头，眉头拧着嘴角绷不住 (17字) 【提取自正文：六厘米的小人……眉头拧着，嘴角却绷不住】
5. `[悬念留白型]` 输了他不认，赢了也不笑，只是… (15字) 【提取自正文：输了他不认，赢了也不笑】

**封面大字**：偷偷让棋的那只手

## 母题 4：人生重大节点的见证 · C 真实客户故事（结构模板）

```

{节点当天，与手办有关的一个具体动作——只写客户讲过的}
{客户提到的一个细节：信物 / 神态 / 一句话}
{手办在这件事里的位置：主桌第一席 / 新家玄关 / 毕业照旁}
```

- 所有细节来自客户原话或授权材料，不添加客户没讲过的情节；
- 发布前请客户过目；可以只展示手办、不展示原照片；
- 本母题允许使用 `[独白对话型]`、`[童真视角型]` 标题（前提是正文里真实发生）。

## 母题 5：写给远行长辈的家常报备 · B 第二人称（改写版）

- **人物**：char_16 推老式二八大杠自行车外公（全身 12cm）
- **档案信物**：水洗深蓝帆布工装夹克（挽袖口）、老式黑色二八大杠、车把上一网兜红苹果；神态为慈祥坚毅、抿嘴含笑
- **单一事件**：放学时校门口，他接过书包、问一句"今天挨批评没"
- **改写说明**：原母题是第一人称写信给逝去的长辈；A/B 视角下改成"邀请读者想一想，如果还能报备一件事"

**正文**
> 如果还能跟外公报备一件事，你会先说哪一件？
>
> 他以前每天四点半推着二八大杠等在校门口，车把上挂着一网兜红苹果。你一出来，他先把书包接过去挂上车把，再问一句："今天挨批评没？"
>
> 那时候嫌他啰嗦，现在才发现，那是他每天最想听的汇报。
>
> 我们照这样一位外公，设计了一尊十二厘米的全身小人：深蓝帆布工装，袖口挽着，扶着二八大杠，车把上那兜苹果红得发亮。
>
> 你最想跟他报备哪件事？是"我工作稳定了"，还是"我也学会等人了"？

**标题**
1. ⭐ `[反问共鸣型]` 还能跟外公报备一件事，你先说哪件 (16字) 【提取自正文：首句】
2. `[场景代入型]` 校门口推着二八大杠的外公，还记得吗 (17字) 【提取自正文：推着二八大杠等在校门口】
3. `[情绪反差型]` 嫌他啰嗦的那句话，原来是他最想听的 (17字) 【提取自正文：那时候嫌他啰嗦……最想听的汇报】
4. `[数字锚点型]` 十二厘米的外公，车把上挂着红苹果 (16字) 【提取自正文：十二厘米的全身小人……车把上那兜苹果】
5. `[悬念留白型]` 每天四点半，校门口总有人在等… (15字) 【提取自正文：每天四点半……等在校门口】

**封面大字**：今天挨批评没？

## 母题 6：封存旧物背后的岁月 · A2 设计手记

- **人物**：char_51 煤油灯下纳千层底鞋垫的老伴奶奶（胸像 6cm）
- **档案信物**：右手中指磨得发亮的牛骨顶针、左手边的粗麻线团、穿在大号钢针上的线头、玳瑁老花镜；神态为安静专注
- **单一事件**：设计时为什么让针脚停在一半

**正文**
> 设计这位纳鞋垫的奶奶，我在她右手中指上留了一枚顶针。
>
> 牛骨的，磨得发亮，内圈被线勒出一道浅槽。顶针要贴着指节，又不能厚得像戒指，定稿时只比米粒宽一点。
>
> 她左手边是一团缠得紧紧的粗麻线，线头穿在大号钢针上，鞋垫的针脚走到一半停住。
>
> 想留的，就是这一停：像有人喊了她一声，她从老花镜上方抬眼应了，手里的针还没放下。
>
> 你见过谁这样纳鞋垫吗？更想留住她低头走针的样子，还是抬眼应你的那一下？

**标题**
1. ⭐ `[手艺人手记型]` 纳鞋垫的奶奶，中指上留了一枚顶针 (16字) 【提取自正文：我在她右手中指上留了一枚顶针】
2. `[悬念留白型]` 针脚走到一半停住，线头还在针上… (16字) 【提取自正文：线头穿在大号钢针上，鞋垫的针脚走到一半停住】
3. `[场景代入型]` 牛骨顶针内圈那道浅槽，你摸过吗 (15字) 【提取自正文：内圈被线勒出一道浅槽】
4. `[数字锚点型]` 比米粒宽一点的顶针，也设计进去了 (16字) 【提取自正文：定稿时只比米粒宽一点】
5. `[情绪反差型]` 想留住的不是针脚，是她停针那一下 (15字) 【提取自正文：想留的，就是这一停】

**封面大字**：她停针的那一下

## 使用提醒

- 范例是**结构与语感**的参考，不要照抄句子；同一句式在账号里反复出现，本身就是同质化；
- A2 视角只写作品上看得见的设计决定，不补写"熬了几个通宵""客户看哭了"之类没有记录的情节；
- 每篇正文末行附："图为 3D 手办设计效果图（AI 生成），实物以打样确认为准。"
