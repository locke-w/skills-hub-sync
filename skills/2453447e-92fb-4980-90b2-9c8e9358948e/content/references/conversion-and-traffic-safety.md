# 合规转化 SOP：评论区运营 · 私信承接 · 授权与交付 (v2.0)

纪念手办是强情感、强信任的品类。能长期做下去的号，靠的是三条底线：
**站内成交**（不导流）· **真实互动**（不刷评）· **授权与隐私**（不乱用客户亲人照片）。

> ⚠️ 所有对外话术中不出现任何建模/修图/AI 软件名，统一用"三维建模 / 数字雕塑 / 全彩树脂打印 / 手工修件"。
> 价格、周期、流程、照片保存期限一律取自 `config/constants.md` 的【业务】参数，不在话术里写死。

## 一、 用词替换字典

| 场景 | 慎用 / 禁用 | 推荐表达 |
| :--- | :--- | :--- |
| 离世 | 死了、死亡、逝者（慎用）；"去美丽星球"等过度隐喻（不推荐，显得轻佻） | 离开、走了、不在了——自然、克制即可 |
| 物件 | 遗物、遗照（慎用）；骨灰、灵堂、墓碑（禁用） | 留下的老物件、老照片、案头一角 |
| 品类 | 死者手办、丧葬用品（禁用） | 纪念手办、掌心手办、定制手办 |
| 价格 | 正文和公开评论里出现价格、"拍下""下单" | "细节可以私信聊"；报价只在私信或店铺商品页 |
| 联系方式 | 微信、电话、二维码、外链，以及"绿泡泡""V我""留个小爪印我来找你"等暗号（禁用） | 站内私信、店铺商品页、官方留资组件 |
| 承诺 | 100% 一模一样、真人复活、永久保存（禁用） | "打印前先确认建模效果，可以修改到满意" |
| 宗教/迷信 | 开光、招魂、保佑、托梦、结缘（禁用/慎用） | 念想、陪伴、放在身边 |
| 软件 | 任何软件或模型名（禁用） | 三维建模、数字雕塑、全彩打印 |

> 替换的目的是**表达得体**，不是**规避审核**。用谐音、拆字、表情去藏联系方式属于"暗示间接导流"，同样违规。

## 二、 评论区运营（只有作者本人与真实用户）

### 1. 置顶评论（作者本人发布，每篇 1 条）

要点：接住正文的单一事件 → 抛出一个读者能回答的问题；**不留联系方式、不报价、不虚构亲历**。

| 笔记视角 | 模板 |
| :--- | :--- |
| A 手艺人手记 | "这尊{人物}最费心思的是{正文里的信物细节}。你家有没有一件被摸得发亮的老物件？讲讲它的故事，我都会看。" |
| B 第二人称 | "写这篇的时候一直在想{正文场景}。你记忆里的{长辈称呼}，最常做的一个动作是什么？" |
| 选购/工艺类 | "常被问的三个问题：只有一张老照片能不能做、做多大合适、多久能到。答案整理在图 7，建议截图。" |
| C 客户授权故事 | "这篇已经过{客户称呼}同意分享。谢谢 TA 愿意把这段记忆交给我们。" |

> 运营者本人有真实亲历（视角 D）时，才可以在置顶里写"我自己也……"。

### 2. 评论回复库（按问题类型，真人逐条回复）

| 用户在问 | 回复要点（改写成自己的话，别整段复制） |
| :--- | :--- |
| 只有一张老照片 / 很模糊 / 黑白的，能做吗 | 能看清五官就可以，黑白、泛黄都没关系；多人合影也能单独做，脸越清楚神态越准。可以私信发来，先免费看看。 |
| 做得像不像 | 打印前会先给你看建模效果，眼神、嘴角、发型都能提修改，确认满意才开始打印。 |
| 多久能到 | 确认模型后约 {制作周期}，{物流}。 |
| 多少钱 | 尺寸和工艺不同价格不一样，私信按你的需求细说。（**公开评论不报数字**） |
| 做多大合适 | 胸像 6cm 适合书桌、床头；全身 12cm 能把手里的老物件也做出来。 |
| 在世的长辈能做吗 | 可以，不少人做来当生日、寿宴或结婚纪念日礼物。 |
| 怎么联系你 | 直接私信就好。（**不给任何站外联系方式**） |
| 用户在讲自己亲人的故事 | **不推销**。回应 TA 故事里的一个具体细节，表达理解即可；对方主动问定制再回答。 |

### 3. 负面与敏感评论应对

| 评论类型 | 应对 |
| :--- | :--- |
| "消费逝者 / 晦气 / 贩卖焦虑" | 不争辩："理解你的感受。做这个是给想留个念想的家庭多一个选择，谢谢你直说。" 正常批评不删除。 |
| "AI 做的吧 / 图是假的" | 坦诚："图是设计效果图，笔记已标注 AI 生成；实物是树脂打印，神态以打样确认为准。" |
| "肯定不像，全靠修图" | 讲流程："打印前会先确认建模效果，不满意可以改。" 有授权的真实交付记录时，引导看相关笔记。 |
| 人身攻击 / 辱骂 | 不回复，按平台规则举报。 |
| 广告 / 引流 spam | 按平台规则删除或举报。 |

### 4. 真实口碑的正确做法

- 交付后邀请客户**自愿**评价，不以返现、赠品换好评；
- 引用客户原话前取得**书面授权**，可匿名、可只展示手办；
- 引用时标注"经客户授权分享"，原话不改写、不拼接；
- **禁止**：小号互动、托儿、伪素人、买评论、互赞群、"评论区剧本"。平台 2025 年起专项打击伪素人与众包账号，一旦被识别，笔记与账号一起受罚。

## 三、 私信承接 SOP（全程站内）

```
[1 共情与需求] → [2 照片评估] → [3 方案与报价] → [4 授权与隐私] → [5 流程与交期] → [6 站内下单] → [7 交付与回访]
```

1. **共情与需求**（先别报价）
   "抱歉让你想起这些。想为谁做？是纪念，还是送给在世的长辈？"
2. **照片评估**
   请对方发照片，按四点看：正脸或 3/4 侧脸、五官清晰、光线均匀、单人或可裁出单人。
   "你发照片来，我先免费看看能不能做、大概是什么效果。"
3. **方案与报价**（取 `config/constants.md` 业务参数）
   说清尺寸差别与适合场景，给 1–2 个方案即可，不催单。
4. **授权与隐私确认**
   "照片只用于这次制作，交付后 {照片保存期限}。以后如果想在笔记里展示成品，会单独问你、签书面同意，可以匿名或只拍手办。"
5. **流程与交期**
   按 `流程` 参数逐步说明：评估 → 建模与五官定型 → 你确认（可修改）→ 打印 → 质检 → 发货。
6. **站内下单**
   通过小红书店铺商品页等站内方式成交；**不引导站外转账、不给外链**。
7. **交付与回访**
   到货后问一句是否完好、摆在哪里；邀请自愿评价（不返现）；客户同意时，可在其指定的纪念日前做一次关怀提醒。

### 常见异议

- **"做出来不像怎么办？"** —— 打印前先看多角度建模效果，眼神、嘴角、发型都能改，确认了才打印。
- **"为什么比普通 3D 打印贵？"** —— 不是开模批量件：每件都要单独建模、五官定型、全彩打印、手工修件，工时都在定制环节。
- **"照片很糊，还有折痕"** —— 先评估，能看清五官轮廓就有机会；实在不行会直说，不硬接。
- **"能加急吗？"** —— 按实际排期回答，不承诺做不到的时间。
- **"能做全家福 / 宠物吗？"** —— 按实际能力回答，不确定就说"先看照片再定"。

## 四、 客户书面授权要点（公开展示前必须完成）

| 项目 | 内容 |
| :--- | :--- |
| 授权人 | 姓名（可不公开）、与照片中人物的关系（须为近亲属） |
| 授权范围 | 仅制作 / 允许展示成品照片 / 允许讲述故事（勾选） |
| 展示方式 | 实名 / 匿名 / 只展示手办不展示原照片 |
| 期限与撤回 | 展示期限；授权人可随时撤回，撤回后下架相关内容 |
| 文件处理 | 原图与模型文件的保存期限与删除方式 |

> 依据：《民法典》第 994 条（死者肖像等由近亲属主张保护）、《个人信息保护法》（最小必要、单独同意）。
