# 小红书分发机制与爆文方法论（运营参考 v2.0）

> **定位**：本文件是生成文案、设计封面与互动时的**方法论参考**。
> **数据口径**：小红书**没有官方公布**推荐算法公式与权重。下文数值均为业内流传的【经验】值，只用来判断"方向"（深度互动 > 浅互动、完读 > 秒划走），**不得在任何对外内容中当作事实引用**，也不作为效果承诺。账号满 10 篇后，一律以创作者中心的自有数据为准（见 `operations-playbook.md` 第 8 节）。

---

## 一、 分发机制：方向性共识

### 1. 互动价值分层【经验】

业内流传的互动加权（CES）写法：

$$\text{互动分} \approx \text{点赞}\times1 + \text{收藏}\times1 + \text{评论}\times4 + \text{转发}\times4 + \text{关注}\times8$$

**可以确定的方向**（与平台"真诚分享"导向一致）：
1. **关注与分享**代表强认可，价值高于随手点赞；
2. **有内容的评论**（讲自己的故事、提具体问题）比表情和"好看"更有价值——业内说法是 ≥15 字长评有额外加权【经验·待验证】；
3. **看完**（翻到最后一张图、停留时间长）是基础质量信号；文题不符导致的"点开就走"会拉低后续分发。

→ 落到文案上：结尾用**具体的二选一问题**邀请读者讲自己的长辈；置顶评论由作者本人抛出问题；不用"求赞求关注"这类无效收尾。

### 2. 流量分发：推荐 + 搜索双入口【经验】

1. **冷启动测试**：新笔记先进小流量池测试，封面点击率与互动率好的笔记会被继续放大（业内常说"首发 2 小时看点击"）；
2. **搜索长尾**：搜索是小红书核心入口之一，被搜索收录的笔记生命周期远长于纯推荐流量——所以标题、正文前 30 字、话题要埋用户真会搜的词（如"老照片做手办""纪念外婆的礼物"）。

### 3. 质量与合规门槛【官方 + 经验】

1. **AI 标识**是法定义务【官方】（《人工智能生成合成内容标识办法》第十条），不标识会被平台加贴并影响账号信任；
2. 信息密度低、排版杂乱、同质化模板内容会被降低分发【经验】；
3. 导流、虚假互动、伪造经历属于平台明确打击对象【官方】（见 `xiaohongshu_ai_rule.md`）。

## 二、 爆款标题公式（非情感类笔记用）

> 情感共鸣型笔记的标题体系见 `copywriting-craft.md`（11 公式 + 文题强对齐）。以下三条用于**选购指南型 / 工艺揭秘型**笔记，同样必须 ≤ 20 字符、与正文内容一致。

| 公式 | 结构 | 心理机制 | 本业务示例（字符数） |
| :--- | :--- | :--- | :--- |
| A 负面预警 + 精准人群 | 想做[X]？这[数字]种[Y]先别[动作] | 损失厌恶、锁定人群 | 想给爸妈做手办？这3种照片先别用（16） |
| B 反常识 + 即时落地 | [对象]做[X]前，先看这[数字]个细节 | 认知冲突 + 可执行 | 老照片做成手办前，先看这3个细节（16） |
| C 清单聚合 + 收藏预期 | 建议截图！[主题]全流程 | 明确收藏动机 | 建议截图！老照片做手办全流程（14） |

## 三、 封面设计（目标：在双列信息流里被点开）

1. **规格**【通行规范】：首图 **3:4 竖图（1080×1440 或 1242×1660）**。首图比例决定整篇笔记在信息流里的外框，一篇笔记内所有图保持同一比例。
2. **安全区**：人物面部、手办主体、大字放在中间区域，上下各留约 8% 不放关键信息，防止被界面遮挡或裁切。
3. **封面大字**：6–10 字，放在上 1/3 留白区，高对比（深底浅字或浅底深字），与标题**互补不重复**（标题讲事，大字讲情绪或悬念）。
4. **首图选择**：优先阶段 2 出图的封面候选视角——07 掌心温存（尺度对比最强）、10 时光重叠（老照片 vs 立体手办的前后对比）。
5. **禁区**：不用 00 写实人像做封面（易被误认为真人照片）；不用真实客户亲人照片做前后对比，除非有书面授权。

## 四、 留存与互动实操

#### 技巧 1：首句钩子
第一句直接进入画面或问题（"你还记得粮站窗口后面那杆秤吗？"），不寒暄、不铺垫。

#### 技巧 2：中段信息卡（提升收藏价值）
选购指南/工艺揭秘型笔记在图序中放一张"定制流程卡/照片自检清单"，标注【建议截图保存】。有用的信息卡本身会带来收藏与截图；"截屏是隐性加权指标"属于【经验·待验证】说法，不作为设计依据。

#### 技巧 3：结尾互动
- **二选一设问**：问题要具体到本篇的信物或神态（"更想留住她盯秤杆的眼神，还是挪秤砣的那一下？"），读者才会写出自己的故事；
- **分享动机**：可以说"转给也记得这杆秤的家人"，**不要出现站外平台名**（如"转到微信家庭群"）；
- **不求赞、不求关注、不留联系方式**。

## 五、 纪念手办业务落地映射

| 目标 | 容易扑街的做法 | 本技能的做法 |
| :--- | :--- | :--- |
| 有内容的评论 | "大家觉得好看吗？" | 结尾二选一问题 + 作者置顶评论抛出"你家有没有一件被摸得发亮的老物件？" |
| 分享 | 孤立自嗨 | 结尾点出"也记得这件事的家人"，引发家庭内分享 |
| 关注 | 纯卖货、无人设 | 手艺人人设：持续发设计手记、工艺细节、真实交付记录（授权） |
| 收藏 | 大段流水账 | 选购指南/工艺揭秘型笔记配流程卡、照片自检清单 |
| 搜索长尾 | 乱堆热门标签 | 核心词 + 场景词 + 长尾词三层话题（见 `operations-playbook.md`） |
| 内容质量 | 空洞煽情、片段拼盘、文题割裂、冒充亲属 | 一文一事 + 依文提炼标题 + A2/B 真实视角 + 人物专属信物 |
