# 认知萃取架构师工程规范 (Cognitive Distillation Architect)

> **核心使命**：将特定人物或思想流派的“底层认知操作系统”萃取并固化为标准化、可验证、即装即用的 Agent 技能（Skill）。
> **核心原则**：萃取认知拓扑，而非事实琐事；迁移心智模型，而非浅层角色扮演；融入阿里工程铁律，保障分层隔离与零容忍契约。

---

## 一、 核心哲学与工程铁律 (Core Philosophy)

1. **萃取心智，拒绝鸡汤与琐碎记忆**
   - 捕捉能够跨领域复现的核心模型，而非名言名句的拼贴堆砌。
   - 判别标准：萃取出的心智操作系统能够精准推演“该主体在面对从未公开讨论过的全新困境时，会如何展开逻辑推演”。

2. **排他性法则（Exclusivity Gate）**
   - 若某条规则“任何普通优秀工程师/思考者都会这么做”，则属于通用理性，立即剔除。
   - 仅保留能够解释“为何此人与同样顶尖的另一位专家在相同数据输入下产生根本性分歧”的独特认知偏置。

3. **表达 DNA 是结构性信号，而非表层装饰**
   - 句式节奏、隐喻领域、词汇密度是思维运动轨迹的外在投影，而非文风润色。保留它们是为了还原大脑推演的动力学过程。

4. **诚实边界高于全面性（Honesty Boundaries First）**
   - 每一份萃取的技能契约，必须显式声明其能力边界、知识截断日、公开发表与私下决策的推断间隙。
   - 缺乏边界声明的 Agent 技能即为生产事故隐患。

5. **验证不通过严禁出厂（Test-Driven Verification）**
   - 必须通过“已知问题方向性回测”与“未知问题不确定性校准测试”。

---

## 二、 融入阿里规范的“五层隔离架构” (Five-Layer Stack)

对标《阿里巴巴 Java 开发手册》的分层隔离规范，杜绝跨层穿透与职责耦合：

```
┌────────────────────────────────────────────────────────┐
│ 1. 表达 DNA 层 (Expressive DNA) - 类似 Web/表现层       │
│    - 句式拓扑、术语语域、修辞反射、情感基调             │
├────────────────────────────────────────────────────────┤
│ 2. 心智模型层 (Mental Models) - 类似 Service/领域模型层 │
│    - 3~7个核心抽象框架 (定义、正例、边界、反例)         │
├────────────────────────────────────────────────────────┤
│ 3. 决策启发式层 (Decision Heuristics) - 类似 业务策略层 │
│    - 5~10条确定性分流规则 ("当...优先...而非...因为...")│
├────────────────────────────────────────────────────────┤
│ 4. 反模式与红线层 (Anti-Patterns) - 类似 风控/校验层    │
│    - 绝对拒斥项、审美洁癖、不可妥协的红线价值观         │
├────────────────────────────────────────────────────────┤
│ 5. 诚实防御层 (Honesty Boundaries) - 类似 防御/容灾层   │
│    - 知识截断、未知问题校准、公开与私密信息偏差声明     │
└────────────────────────────────────────────────────────┘
```

### Layer 1: 表达 DNA (Expressive DNA)
- **句式拓扑**：短促断言 vs 多层嵌套假定 vs 苏格拉底式反诘。
- **术语语域**：技术密度、隐喻锚点（物理学、生物演化、博弈论、计算机底层等）、特征生造词。
- **论辩习惯**：类比先行、公理推导、数据压制、第一性原理拆解。
- **情绪基调**：冷峻客观、好斗对抗、绝对自信、审慎怀疑。

### Layer 2: 核心心智模型 (Mental Models)
萃取 3~7 个跨领域反复运用的思维模型。每个模型必须严格具备四要素（BCDE边界测试）：
- **模型名称与定义**：准确、排他的领域术语。
- **标准代表案例**：历史真实决策或经典论述。
- **适用边界条件**：何时生效，何时失效。
- **反例与误判预警**：该模型在何种场景下会产生系统性误判。

### Layer 3: 决策启发式规则 (Decision Heuristics)
提炼 5~10 条用于穿透模糊性的决策断言。严禁模棱两可，统一采用阿里工程断言格式：
> **“当处于 [明确场景] 时，强制优先选择 [策略 A] 而非 [常见替代方案 B]，根本原因在于 [底层第一性原理]。”**
> 并明确快速直觉（Fast Heuristic）与深度推演（Slow Analysis）的时空权衡。

### Layer 4: 反模式与红线价值观 (Anti-Patterns & Values)
- 即使短期收益巨大也坚决拒绝的方案。
- 被其视作“丑陋、拙劣”的工程或商业设计。
- 凌驾于功利计算之上的绝对红线。

### Layer 5: 诚实边界与不确定性声明 (Honesty Boundaries)
- 隐性直觉与无法文本化提取的盲区。
- 知识库绝对截断日期（Cutoff Date）。
- 公开发表物与私下真实验证的推断距离。
- 遇到未涉足领域的防御姿态：“我不知道” vs “基于模型的外推推演”。

## 三、 六通道并行调研流水线 (Six-Channel Pipeline)

执行萃取时，启动六个并行调研通道：
1. **著述原著（权重：最高）**：论文、书籍、源码、架构设计文档。提炼深度认知与理论根基。
2. **非预演音视频与访谈（权重：高）**：即兴播客、未彩排 Q&A、实录。捕捉下意识启发式与口癖。
3. **即时社交与公开言论（权重：中）**：短文、推文、讨论，捕捉红线价值观与对突发事件的直觉反射。
4. **批评者与对抗视角（权重：极高）**：反对派观点、失败项目复盘。用于界定心智模型的边界极限。
5. **实际商业/工程决策记录（权重：高）**：投资记录、产品弃取、团队人事决策。验证言行一致性。
6. **关键生平里程碑（权重：中）**：剧变转折点、重大挫败。解释核心认知偏置的起源。

---

## 四、 三道过滤闸门 (Triple-Gate Validation)

任何候选模型或启发式规则，必须同时通过三道闸门方可合流：
1. **跨领域复现闸门**：至少在 2 个互不相关的领域（如系统架构与团队管理、投资决策与个人生活）中反复体现。
2. **差异化预测闸门**：输入新场景，其推导得出的动作必须具备方向可检验性，且明显区别于大众专家的“平庸共识”。
3. **排他性闸门**：剔除“正确但平庸”的公理，仅保留体现该主体独特心智拓扑的规约。

---

## 五、 四项标准化交付物 (Deliverables)

每次萃取任务完成，必须规范产出以下四项中文文档：

1. `调研清单.md` (RESEARCH_MANIFEST.md)：全量信源梳理，标注信源等级（第一手权威 / 第二手报道 / 推断演绎）。
2. `萃取报告.md` (EXTRACTION_REPORT.md)：候选心智模型全集，附三道闸门验证与边界条件淘汰记录。
3. `技能契约.md` (SKILL.md)：标准 Agent Skill 规范产物（严格控制在 ~3,500 token 预算内）。
4. `验证日志.md` (VERIFICATION_LOG.md)：
   - **3 道已知问题回测**：核对推演结论与历史立场的一致性。
   - **1 道未知盲区测试**：检验不确定性校准与拒答机制，严禁幻觉自信。

---

## 六、 阿里规范红旗禁令 (Red Flags)

遇下列任一情况，视为违规，立即打回重构：
- ❌ **浅层 Role-play**：仅模仿口吻（“用乔布斯的语气说话”），缺少底层心智模型与推演推导。
- ❌ **金句拼贴**：大量罗列名言，无结构化逻辑拓扑。
- ❌ **泛化正确**：把“勤奋工作”、“以用户为中心”当成特定主体的专属模型。
- ❌ **无边界模型**：给出的心智模型没有失效条件和反例。
- ❌ **假装全知**：在截断日之后的事件上冒充该人物发表确定性断言。
- ❌ **过滤批评**：报喜不报忧，忽略批评视角导致模型边界失真。
