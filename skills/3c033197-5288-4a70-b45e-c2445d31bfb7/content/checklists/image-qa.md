# 出图验收清单（发布前逐张检查）

对应 `references/character/scene-library.md` 第 6 节；由 `inspect_images.py` 给出尺寸/命名/比例机器结论，本清单负责人工目检项。

| 项目 | 通过标准 |
| :--- | :--- |
| 人物一致性 | 01 手办与 00 是同一个人：骨相、发型、专属信物一致；场景图里的手办与 01 一致 |
| 手部 | 五指、关节自然；07 掌心图无多指、断指、融合手指 |
| 尺度 | 6cm 胸像 / 12cm 全身像与手掌、杯子、钥匙等参照物比例合理 |
| 文字伪影 | 无英文字母、乱码、招牌字、水印、软件 logo |
| 材质 | 手办是哑光树脂质感：没有真人毛孔，也不是亮面塑料；底座为深色工艺品底座，不像石膏柱或墓碑 |
| 氛围 | 温暖、克制；无阴森暗角、惊悚光影、灵堂供桌意象（不放黑白证件照相框、香炉、红烛、祭品、神龛） |
| 画幅 | 00/01 为 1:1；02–10 为 3:4（`inspect_images.py` 核对，非 3:4 已被居中裁切）；封面候选 07/10 上 1/3 有干净留白 |
| 命名 | `0.jpg`、`1.jpg`、`视角NN_{槽位名}.jpg`，无重名、无未下载占位 |
| 合规 | 无真实名人面孔，无网络真人照片垫图痕迹；画面无真实客户照片（除非书面授权） |
| 状态机 | `inspect_images.py` 结论为 REUSE 才允许进入文案与发布；EMPTY/INCOMPLETE 先补图 |
