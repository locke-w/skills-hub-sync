# 3D 打印成品效果图与图生图决策工作流指南

> **v5 归属说明**：本文件原属 xiaohongshu 文案技能，v5 起迁入 fullcolor，作为**有 3D 模型文件时的可选工作流**。
> 文中"SKILL.md 6步算法"指 `prompt-engineering-spec.md` 的六步法（v5 增加 Step 7 场景图规则）；笔记用场景图统一 3:4。

本指南详解**"Blender 物理光学级底模渲染 ➔ 图生图/文生图决策 ➔ 模块化 Prompt 引擎组装 ➔ 直接调用 generate_image"**的核心技术路径。

---

## ⚠️ 两轨严格隔离铁律

**第一轨（Blender渲染）** 和 **第二轨（generate_image矩阵生图）** 是完全独立的两个产出。

> **禁止将 Blender 渲染角度（3/4视角、正视特写、侧面光影、微距五官）当作 generate_image 的生图任务。**
>
> - `generate_image` 生图永远走 **SKILL.md 6步算法 + nano-banana-hyperrealistic-engine.md 骨架模板 + github-diorama-staging-matrix.md 矩阵抽选**，产出的是"真实场景摆拍/实拍风格图"。
> - Blender 渲染角度只属于第一轨，是 Blender Cycles 的输出产物。用户没有提供 Blender 模型时，**第一轨输出为空**，不能用 generate_image 伪造替代。

## 一、 图生图 vs 文生图决策树

```
用户请求生成效果图/配图
        │
        ▼
用户提供了 Blender 渲染图 / 老照片底图？
  ├─ YES → 【图生图模式】
  │   │
  │   ├─ 提供了多角度渲染图？
  │   │   ├─ YES → 选最佳 3/4 角度作为主参考（ImagePaths）
  │   │   └─ NO  → 使用唯一可用图作为参考
  │   │
### 3. 外部生图平台（Midjourney / Fooocus / SD / 即梦）垫图与人物一致性保证指南

当云端生图配额受限，需将 Blender 渲染图拿到外部平台生图时，**千万不要盲目把 4 张图全部塞入**，遵循以下行业级一致性法则：

| 生图平台 | 推荐垫图方案 | 核心参数与权重配置 | 关键效果与防翻车要点 |
| :--- | :--- | :--- | :--- |
| **Midjourney (v6.1)** | **首选单图**：`01_经典3-4视角.png`<br>*(可选双图：01 作为主图 + 02/04 充当 cref)* | 格式：`[01图片URL] [Prompt] --ar 3:4 --cref [02图片URL] --cw 100 --iw 1.5` | `--cw 100` 强行锁定脸部五官与发型；`--iw 1.5` 保持手办材质与衣物色彩，不要放侧面图以免视角打架。 |
| **Fooocus / SD WebUI** | **单图 IP-Adapter / Image Prompt**：<br>`01_经典3-4视角.png` | `Image Prompt Weight`: **0.65 ~ 0.75**<br>`Stop At`: **0.85** | 权重 >0.85 会导致背景无法生成新环境；权重 <0.5 会导致人物不像。0.7 为黄金平衡点。 |
| **即梦 (Jimeng) / 智谱清影 / Liblib** | **图生图 / 参考生图**：<br>`01_经典3-4视角.png` | **重绘幅度 / 参考强度**：<br>设为 **0.55 ~ 0.65** | 保持主体人物脸型、衣服格子与眼镜特征，同时生成木窗台、灶台等新生活场景。 |

> 💡 **为什么首选 `01_经典3-4视角` 作为主垫图？**
> 1. **结构信息最丰富**：3/4 视角同时包含了正面五官、眼角笑纹、脸颊立体转折、肩膀服装纹理（如蓝绿格子衫）以及帽子结构；
> 2. **避免扁平与死板**：纯正面大头照（02/04）容易让 AI 生成出呆板的正脸贴图感；
> 3. **避免视角冲突**：如果把正视、侧面、微距 4 张图同时扔给同一个参考通道，AI 会在“向左看向右看”之间注意力混乱，造成脸部扭曲。

## 二、 第一轨：Blender 物理光学级微缩摄影棚渲染

> **触发条件**：用户提供了 `.obj` / `.fbx` / `.blend` 3D 模型文件，或主动要求 Blender 渲染。
> 没有模型文件时，本轨跳过，**不要用 generate_image 模拟摄影棚渲染角度**。

### 1. 标准渲染角度（仅供 Blender Cycles 使用，不是生图任务）

```
渲染效果图/
├── 01_经典3-4视角_透视实拍.png      # 经典黄金透视角（Blender Cycles）
├── 02_正面半身特写_手办视角.png      # 正视手办特写（Blender Cycles）
├── 03_侧45度微仰视_光影雕塑感.png    # 侧面雕塑感（Blender Cycles）
└── 04_面部五官与微距特写.png         # 微距特写（Blender Cycles）
```

> 以上 4 张全部由 Blender Cycles 渲染产出，**不通过 generate_image 生成**。

### 2. 物理材质参数配方
* **微弱次表面散射 (SSS)**：
  - `Subsurface Weight` = `0.04`，`Subsurface Radius` = `(0.015, 0.008, 0.005)`
* **哑光粗糙度**：
  - `Roughness` = `0.42`，`Specular` = `0.45`

### 3. 摄影棚三点布光系统
* **主光 (Key Light)**：暖柔光 `(1.0, 0.96, 0.92)`，45°斜上方，160W
* **辅光 (Fill Light)**：冷调弱光 `(0.92, 0.95, 1.0)`，柔化阴影，55W
* **轮廓背光 (Rim Light)**：高能白光，锐化轮廓，140W
* **展台底座**：深灰磨砂倒角圆盘 + 浅灰无缝背景

### 4. 一键渲染脚本调用
```bash
/Applications/Blender.app/Contents/MacOS/Blender --background \
  --python "{脚本目录}/render_print_preview.py" \
  -- -i "{模型文件路径}.obj" -o "/Users/wuyongjia/3D打印/3dprint-xhs-思念/{会话名称}/渲染效果图"
```
> `{会话名称}` 取值规则见 SKILL.md 铁律三。渲染前先确认输出目录已创建。

## 三、 第二轨：generate_image 矩阵生图（实景实拍风格）

> **触发条件**：任何情况下，只要用户要生图，本轨就执行。
> 产出的是"真实场景摆拍/生活实拍风格"，**与 Blender 渲染角度完全无关**。

### 标准产出（纯文生图时）

```
渲染效果图/
├── 05_[手法]_[环境]_[光影].jpg    # [generate_image] 矩阵动态抽选
├── 06_[手法]_[环境]_[光影].jpg    # [generate_image] 矩阵动态抽选
└── ...（按用户要求张数，文件名含手法+环境+光影三要素）
```

> 文件名格式：`序号_手法简称_环境简称_光影简称.jpg`
> 例：`05_掌中凝视_木窗台_晨曦黄金.jpg`、`06_前实后虚_老相册_冷调薄雾.jpg`

### 执行步骤
1. **按 SKILL.md 第一节 6 步算法执行**
2. **从 `nano-banana-hyperrealistic-engine.md` 获取**：手法骨架模板 → 填入占位符
3. **从 `github-diorama-staging-matrix.md` 获取**：环境/道具/光影 Prompt 片段
4. **拼装 Negative Prompt**：通用基底 + 场景增补
5. **查画幅映射表**确定 AspectRatio
6. **直接调用 `generate_image`** → 归档

## 四、 两轨产出汇总（有 Blender 模型时的完整交付）

```
渲染效果图/
├── 01_经典3-4视角_透视实拍.png      # [第一轨 Blender] 摄影棚经典视角
├── 02_正面半身特写_手办视角.png      # [第一轨 Blender] 摄影棚正视特写
├── 03_侧45度微仰视_光影雕塑感.png    # [第一轨 Blender] 摄影棚侧面雕塑
├── 04_面部五官与微距特写.png         # [第一轨 Blender] 摄影棚微距细节
├── 05_掌中凝视_[环境]_[光影].jpg    # [第二轨 generate_image] 封面级掌心微距大片
├── 06_前实后虚_[环境]_[光影].jpg    # [第二轨 generate_image] 岁月信物/老照片同框
├── 07_前虚后实_[环境]_[光影].jpg    # [第二轨 generate_image] 烟火日常/生活空间
├── 08_指尖传递_[环境]_[光影].jpg    # [第二轨 generate_image] 案头温暖触碰
└── 09_巨物俯视_[环境]_[光影].jpg    # [第二轨 generate_image] 庭院微缩守护
```

> **没有 Blender 模型时**：01~04 跳过，由第二轨 `generate_image` 连续生成 5~6 张不同场景与视角的真实摆拍大片（05~10）。
> **有 Blender 模型时**：先运行脚本产出 01~04，然后以 `01_经典3-4视角_透视实拍.png` 作为 `ImagePaths` 参考底图传入第二轨，连续生成 05~09，实现面部神态一致的 9 张全套大片！
