# 文案工艺手册：叙事视角 · 单一事件 · 五层结构 · 标题体系 (v1.0)

> 本文件承接 SKILL.md 工作流 Step 3–5。数值（字数、字符、Emoji、标签数）以 `config/studio.toml` + `config/copy_lexicon.json` 为准；写完后用 `scripts/validate_copy.py` 自动校验。

---

## 1. 叙事视角矩阵（先定视角，再动笔）

素材库里的长辈人物都是 **AI 虚构的示例角色**。把他们写成"我奶奶""我爸"的真实经历，就是把合成内容谎称为真实——《标识办法》与小红书用户协议明确禁止，平台也在专项打击伪素人。所以动笔前先定视角：

| 视角 | 适用条件 | 文中的"我"是谁 | 能写 | 不能写 |
| :--- | :--- | :--- | :--- | :--- |
| **A1 手艺人制作手记** | 这尊手办已实物打印，运营者有真实制作记录 | 做手办的人 | 真实的建模、打印、修件、上色过程 | 编造耗时、版本数、客户反应 |
| **A2 手艺人设计手记**（默认） | 只有效果图 | 设计这尊手办的人 | **作品上看得见的**设计决定：为什么加这枚顶针、为什么让他眯着左眼 | "打磨了三天""拿给同事看她哭了"等无记录的过程与情节 |
| **B 第二人称代入**（默认） | 任何情况 | 基本不出现"我"；落点可用"我们照这样一位××设计了……" | 用"你"唤起读者自己的长辈记忆，描写一个具体生活切面 | 声称作者亲历 |
| **C 真实客户故事** | 有客户书面授权 | 客户（或以第三人称转述） | 客户讲述的真实细节，标注"经客户授权分享"，可匿名 | 为了煽情改写或拼接情节 |
| **D 运营者本人经历** | 运营者确认属实并愿意公开 | 运营者本人 | 真实经历 | 虚构或夸大 |
| ❌ **禁用** | —— | 冒充 AI 虚构人物的亲属 | —— | "今天我把奶奶那杆秤摘下来……" |

```
有客户书面授权的真实故事？ ──是──▶ C
        │否
运营者本人真实经历且愿意公开？ ──是──▶ D
        │否
手办已实物打印且有真实制作记录？ ──是──▶ A1（也可用 B）
        │否
        ▼
A2 或 B（默认；同一人物的多篇笔记可交替使用）
```

**图片声明**：A2、B 视角的配图是 AI 效果图，正文末行必须附"图为 3D 手办设计效果图（AI 生成），实物以打样确认为准。"，且全文不得出现"实拍、成品图、买家秀"。

## 2. 单一事件定格：一文只讲一件事

整篇正文只聚焦**一个特定时空切片里的一件事**，用显微镜写深写透：

| 视角 | "一件事"是什么 | 例 |
| :--- | :--- | :--- |
| A | 一个设计/工艺取舍 | 修表老爷爷右眼那只放大镜，怎么夹在眉骨和颧骨之间 |
| B | 读者记忆里的一个生活切面 | 粮站窗口，秤砣挂上铜勾、她盯住秤杆的那几秒 |
| C / D | 一个真实发生的事件 | 客户婚礼当天，把手办放在主桌第一席的那一刻 |

**❌ 反例**：
1. **编年史走马灯**："小时候他给我做红烧肉，初中骑车送我上学，大学送我上火车，今天整理旧物……"
2. **场景大杂烩**："他在厨房做饭，又在阳台浇花，书桌里还有他的算盘……"
3. **空洞抒情 + 碎片**："他是一个很好的人，一辈子为家操劳……"

**✅ 可选切片**：物件特写（顶针内圈那道浅槽）· 生活现场（揭砂锅盖尝第一口汤）· 味觉复现（那碗葱油面少的一勺火候）· 设计取舍（放大镜后那只眯着的眼）· 童真发问（仅 C/D 真实发生，A/B 只能写成假设"如果孩子问起……"）。

## 3. 正文五层微结构（180–220 字 · 去八股多样化升级）

> ⚠️ **反同质化禁令**：2026 小红书星云 5.0 算法对句式结构相似度 >70% 的模板化文案直接限流。**严禁篇篇用"设计这位XX，最费心思的是…"或"你家是不是也有…"开头；严禁第四段写成"场景图里，她身边是…"的提示词报菜名；严禁结尾篇篇机械套用同一种问卷腔！**

| 层 | 字数 | 任务 | B 视角（第二人称记忆唤醒）多样化示范 | A2 视角（手艺人设计手记）多样化示范 |
| :--- | :--- | :--- | :--- | :--- |
| ① 切入 | ≈30 | **5 种开篇钩子轮换**：①声音/动作突入 ②老物件微距 ③口头禅/吆喝声 ④工艺取舍直入 ⑤记忆画面叩问 | `"叮——"黄铜钥匙碰响门后铁钩，那是他下班进门的第一声动静。` / `你还记得粮站窗口后面那杆秤吗？` | `"没有金刚钻，不揽瓷器活。"谁家碗摔成两瓣，他都说别扔。` / `右手中指那枚牛骨顶针，内圈被麻线勒出一道浅槽。` |
| ② 细节 | ≈50 | 深挖这件事的动作、声音、气味、触感，**不跳到别的年份** | 铁栅窗一拉开，秤砣挂上铜勾，窗口里的阿姨眯着眼盯住秤杆…… | 镜筒夹在眉骨和颧骨之间，松了像挂着，紧了又像在皱眉…… |
| ③ 拐点 | ≈50 | 从一个细节里提炼克制的情绪落差（嘴硬心软 / 动作定格） | 可碰上抱着孩子来买粮的，她会把秤砣悄悄往外挪一点点。 | 想留的正是这一停：像有人喊了她一声，她从老花镜上方抬眼应了。 |
| ④ 手办闭环 | ≈40 | **自然融入案头陪伴**（严禁写"场景图里…"或生硬罗列参数） | 把这一幕定格成六厘米的掌心小人：深蓝罩衫，黑袖套，手里那杆秤连秤星都留着。 | 做成六厘米的胸像立在书桌角，赭石粗布褂，手心还捏着那枚小铜钉，抬眼就能看见。 |
| ⑤ 互动 | ≈30 | **高 CES 故事召唤**：围绕信物/口头禅/动作抛出有温度的追问 | 你家也有这样一位嘴硬心软的长辈吗？更想留住她盯秤杆的眼神，还是挪秤砣的那一下？ | 你家里还留着哪件被长辈磨得发亮的老物件？看到它，最先想起的是他低头干活，还是抬头冲你笑？ |

## 4. 去 AI 味 8 条铁律

| # | 铁律 | 正例 | 反例 |
| :---: | :--- | :--- | :--- |
| ❶ | 禁用华丽空洞词 | 碗底还有锅巴的焦香 | 不可磨灭的温度 / 深刻的爱 |
| ❷ | 禁用机械连接词 | （直接换行过渡） | 首先…其次…最后… / 值得一提的是 |
| ❸ | 感官优先于抒情 | 围裙上总有油烟的味道 | 她的爱无处不在 |
| ❹ | 动作优先于形容 | 他把苹果一个个擦亮塞进书包 | 他是一个无比慈祥的老人 |
| ❺ | 克制胜于宣泄 | 厨房的灯再也没亮过 | 眼泪像断了线的珠子 |
| ❻ | 口语化但不幼稚 | 想想都觉得亏欠 | 绝绝子太破防了呜呜 |
| ❼ | 每句都有信息增量 | 每句推进一个事实或画面 | 换个说法重复同一件事 |
| ❽ | 禁用时空跳跃拼接 | 下午推开老书房的门… | 小时候…后来…工作后…如今… |

## 5. 正文禁写清单

- **陈词滥调**：瞒着全家做决定、眼泪砸在键盘上、冰冷的树脂有了体温、爱没有消失只是换了种方式、总觉得来日方长、子欲养而亲不待；
- **病因与事故细节**：癌症、心梗、车祸、抢救等（避免卖惨与死亡焦虑）——人物档案里的病因只作为设计背景，不进正文；
- **价格、联系方式、站外平台名**；
- **任何软件或模型名**；
- **绝对化承诺**：一模一样、100% 还原、复活、永久保存；
- **迷信与丧葬意象**：保佑、托梦、开光、骨灰、灵堂、墓碑。

## 7. 12 大叙事母题

> 母题描述的是**人物的生活**，决定画面与信物；在 A/B 视角下，它塑造场景，而不是作者的身世。母题 5/8/10/12 天然带第一人称关系（写信、语音、婚礼留座、带着手办旅行），A/B 视角下改写为第二人称邀请（"如果还能跟他报备一件事……"）或设计手记；第一人称只用于 C/D。

1. **劳作者手记与手艺的温度**：老茧双手、规整图纸、磨损旧工具；
2. **舌尖味蕾与柴米油盐**：只有 TA 掌握的那勺火候；
3. **嘴硬心软的倔老头**：有笑有泪的反差与无声关照；
4. **人生重大节点的见证**：毕业、乔迁、升职、婚礼；
5. **写给远行长辈的家常报备**：阳台花开了、孩子会叫人了；
6. **封存旧物背后的岁月**：铁盒、发条表、算盘、旧相册；
7. **如山父爱与未说出口的骄傲**：抽屉深处压着的奖状与剪报；
8. **空巢母亲的语音与半生托举**："出门慢点、按时吃饭"；
9. **双向奔赴的公婆深情**：临走塞在沙发垫下的存折、起早炖好的汤；
10. **婚礼上的红眼眶**：交出女儿时颤抖的手、主桌第一席；
11. **被塞爆的后备箱**：后视镜里越来越小的身影；
12. **来不及享福的遗憾**：把手办带上副驾、高铁靠窗位、海边。

六个母题的完整范例见 `emotional-story-templates.md`。

## 8. 标题体系

### 8.1 正文先行，依文提炼
先写完正文，再从正文里的信物、动作、对白、反差提炼 8 条标题。标题里的主语、信物、动词必须在正文里找得到；每条标注【提取自正文：……】。文题不符会导致点开就走，拉低后续分发。

### 8.2 字符规则
- 平台上限 20 字符，推荐 14–19；
- 汉字、字母、数字、标点各计 1；**Emoji 按保守口径计 2**；
- 每条标题最多 1 个 Emoji，放在末尾；
- 标注的字数以 `validate_copy.py` 的计算结果为准（模型心算字数经常出错）。

### 8.3 11 大高点击标题公式（黄金前 5 字 + 反差钩子）

> **拒绝平庸铁律**：
> 1. **前 5 字必须抓人**：用【反差动作】、【具体数字（六厘米/十二厘米）】、【时代信物特写】或【记忆痛点】开篇；
> 2. **禁止千篇一律写"XX最费心思"作为首推**，禁止直接截取正文半句无悬念描写充数；
> 3. 首推（⭐）优先选择 **情绪反差型**、**悬念留白型** 或 **场景记忆唤醒型**。

| # | 公式 | 视角限制 | 高点击示例（字符数） |
| :---: | :--- | :--- | :--- |
| ① | 情绪反差型 | 通用（⭐首推优选） | 一两都不肯差的她，偷偷挪了秤砣（15） |
| ② | 悬念留白型 | 通用（⭐首推优选） | 碰上抱孩子买粮的，她会把秤砣…（15） |
| ③ | 场景代入型 | 通用 | 粮站窗口后面那杆秤，你还记得吗（15） |
| ④ | 独白对话型 | **仅 C/D** | 妈，你那杆秤我一直挂在厨房墙上（15） |
| ⑤ | 身份标签型 | 通用 | 排队买过粮的人，都懂这一点点（14） |
| ⑥ | 数字锚点型 | 通用（带搜索词） | 六厘米的售粮员，秤星一颗颗都留着（16） |
| ⑦ | 反问共鸣型 | 通用 | 你家也有一位嘴硬心软的长辈吗（14） |
| ⑧ | 时空对比型 | 通用 | 那会儿看不懂的一点点，长大才明白（16） |
| ⑨ | 童真视角型 | C/D 真实发生；A/B 只能是假设句 | 如果孩子问起那杆秤，你会怎么说（15） |
| ⑩ | 仪式治愈型 | 通用（A/B 用建议语气） | 老秤旁边留个位置，给挪秤砣的她（15） |
| ⑪ | 手艺人手记型 | **仅 A**（写具体取舍，禁套话） | 放大镜后那只眯着的眼，最难也最像（16） |

## 9. 封面大字（6–10 字）

封面大字与标题**互补不重复**：标题讲事，大字讲一个动作、一句对白或一个问题。

| 类型 | 示例 |
| :--- | :--- |
| 动作特写 | 挪秤砣的那一下 |
| 对白 | 她只说"正好" |
| 反问 | 你还记得这杆秤吗 |
| 设计取舍 | 放大镜后那只眼 |

## 11. 交付前自检（机器可查的部分交给校验器）

- 视角已声明，且 A/B 视角下没有"我奶奶/我爸"式亲属叙事；
- 一文一事，没有多时空拼接；
- 五层齐全，结尾是本篇专属的二选一问题；
- 8 条标题都能在正文里找到出处，覆盖 ≥5 种公式；
- 没有禁写清单里的词；
- 运行 `python3 scripts/validate_copy.py <小红书文案.md>`，BLOCKER = 0。
